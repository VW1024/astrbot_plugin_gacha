# 本地文件抽卡

本插件在开发过程中使用了 AI 辅助（部分代码编写帮助、UI 制作、文档整理）。
纯本地存储、自带 WebUI 管理面板的抽卡插件。所有卡池、卡片、图片、权重以文件形式组织，方便备份、迁移、版本管理，不依赖任何数据库或外部服务。

---

## 功能与优势

**纯本地存储**

所有内容以文件形式保存在 AstrBot 数据目录。卡池、卡片、权重、记录均为可读 JSON / 纯文本，随拷随走，不锁数据。支持任意数量卡池，每个卡池独立配置。

**WebUI 管理面板**

内置三栏式管理界面（卡池 / 卡片 / 详情），在浏览器里直接修改字段、权重、图片，实时预览。带编辑事务：改动先进草稿，可撤回、可放弃、可保存。还有抽卡效果预览功能，编辑时即可看到最终显示效果。

**抽卡玩法**

每张卡片可单独设置权重，实时查看出货概率。每日次数按「群聊 + 用户 + 卡池 + 日期」独立计数，跨群不干扰。支持群白名单、before / after 演出气泡、卡池级默认提示词、多图兼容。

**图片管理**

浏览器直接上传 / 替换 / 删除图片，上传时自动压缩到 512px 内，仅支持 PNG 格式。

---

## 使用前须知

- 图片仅支持 PNG，单张不超过 5MB
- 上传的图片会自动缩放到最长边 512px
- 编辑模式是单例的，同一时间只有一个管理员能进入
- 编辑中途重启容器会丢失未保存的草稿

## 安装

在 AstrBot 插件市场搜索 `本地文件抽卡` 或 `astrbot_plugin_gacha` 安装。

或克隆到 AstrBot 的 `data/plugins/` 目录下，重启 AstrBot。

---

## 快速上手

1. 群里发送 `/查看卡池`，确认插件已加载
2. 打开 AstrBot WebUI 的插件页，点「卡池管理」进入面板
3. 点「进入编辑模式」，点 `+` 新建卡池
4. 上传图片、填写字段，点「保存当前编辑」
5. 群里发送 `/抽卡 卡池名` 试试

## WebUI 面板

打开 AstrBot WebUI 的插件页，点「卡池管理」进入面板。

使用流程：

1. 点「进入编辑模式」，顶部按钮切换为「放弃修改 / 撤回 / 保存当前编辑 / 结束编辑」
2. 点一个卡池开始编辑，左侧出现绿色标记
3. 修改字段、权重、图片，失焦自动保存到草稿
4. Ctrl+Z 或点「撤回」撤销上一步
5. 「保存当前编辑」落盘但不退出，「结束编辑」保存并退出

编辑模式是单例的，同一时间只有一个管理员能进入。

## 配置说明

### config.json

| 字段 | 说明 | 默认 |
|---|---|---|
| `default_daily_limit` | 新建卡池的默认每日次数 | `1` |

### pool.json

| 字段 | 说明 |
|---|---|
| `display_name` | 展示名，默认用文件夹名 |
| `daily_limit` | 每日抽卡上限 |
| `group_whitelist` | 群白名单，空 = 对所有群开放 |
| `private_whitelist` | 私聊白名单，空 = 禁止私聊，填用户QQ则允许 |
### weights.json

权重为正整数，缺失或非法时自动降级为 50。概率 = 该卡权重 / 所有卡权重之和。

### records.json

键格式：`{group_id}_{user_id}_{pool_name}_{date}`

- 群聊：`123456789_987654321_卡池名_2026-10-16`
- 私聊：`0_987654321_卡池名_2026-10-16`

插件启动时和每次打开 WebUI 时自动清理，只保留今天和昨天的记录。

---

## 其他说明

- 抽卡串行执行，多人同时抽卡会排队
- 私聊不受群白名单限制
- 卡片目录为空时仍视为有效卡，只输出卡名

## 目录结构

所有数据保存在 AstrBot 数据目录（`data/plugin_data/gacha/`）：

- `config.json` — 全局配置
- `pool_index.json` — 卡池索引
- `records.json` — 抽卡记录
- `edit_lock.json` — 编辑锁
- `pool/` — 卡池根目录
  - `卡池名/`
    - `pool.json` — 卡池配置
    - `weights.json` — 卡片权重
    - `default_announce.txt` — 卡池默认提示
    - `cards/`
      - `卡名/`
        - `*.png` — 图片
        - `desc.txt` — 描述
        - `announce.txt` — 抽卡提示
        - `name.txt` — 展示名称
        - `before.txt` — 前置气泡
        - `after.txt` — 后置气泡

所有 txt 均为可选，空文件或缺失则不输出对应部分。
